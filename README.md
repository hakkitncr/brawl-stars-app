# 🎮 Brawl Stars Web App

## 📌 Projectbeschrijving

Dit project is een interactieve webapplicatie gebouwd met JavaScript en Vite. De app gebruikt een API om Brawl Stars brawlers te tonen.

Gebruikers kunnen zoeken, filteren, sorteren en favorieten opslaan.

---

## 🚀 Functionaliteiten

* Zoekfunctie
* Filter op rarity
* Sorteren (A-Z / Z-A)
* Favorieten opslaan
* Popup met details
* Dark / Light mode

---

## 🌐 API

https://api.brawlapi.com/v1/brawlers
